# 🎵 HTML Audio and Video Player

A simple multimedia webpage created while learning HTML with **freeCodeCamp**.

## 📌 About the Project

This project demonstrates how to embed both **audio and video content** into a webpage using HTML5 multimedia elements.

The page contains:

* 🎬 A video demonstrating the JavaScript `map()` method
* 🎵 An audio track called "Sailing Away"

## 🛠️ Technologies Used

* HTML5
* `<video>` element
* `<audio>` element
* `<section>` element

## ✨ Features

* 🎬 Embedded video player
* 🎵 Embedded audio player
* ▶️ Built-in playback controls
* 🔁 Audio loop functionality
* 📱 Responsive viewport configuration
* 📂 Organized content using HTML sections
